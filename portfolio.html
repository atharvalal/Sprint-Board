// A LITTLE CONTEXT

Somewhere between “view source” and “where did I put that resistor?”

I'm Atharva — people call me athu — a developer and AI student who enjoys moving between different worlds: shipping full-stack products with Next.js, React and Node, wiring up ESP32-based IoT systems, and exploring how machine learning and AI agents can solve useful problems.

My recent work spans production-style sites for real businesses alongside Java, Python and embedded systems coursework. I'm especially curious about machine learning, agentic AI and the systems that let intelligent software take meaningful action.

I like readable code more than clever code, and I'd rather ship something simple that works than something impressive that doesn't.
